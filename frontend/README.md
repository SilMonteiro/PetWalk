# Projeto de Registro de Animais de Estimação

Este projeto é uma aplicação frontend simples construída com React e Vite. Ele consiste em uma tela de login e uma tela de registro de animais de estimação.

## Estrutura do Projeto

```
frontend-project
├── public
├── src
│   ├── components
│   │   ├── LoginScreen.jsx
│   │   └── PetRegistrationScreen.jsx
│   ├── styles
│   │   ├── login.css
│   │   └── pet-registration.css
│   ├── App.jsx
│   └── main.jsx
├── package.json
├── vite.config.js
└── README.md
```

## Instalação

1. Clone o repositório.
2. Navegue até o diretório do projeto.
3. Execute `npm install` para instalar as dependências.

## Execução

Para iniciar o servidor de desenvolvimento, execute:

```
npm run dev
```

A aplicação estará disponível em `http://localhost:3000`.

## Funcionalidades

- Tela de login com campos para email e senha.
- Tela de registro de animais de estimação com campos para nome do pet, tipo e idade.

## Tecnologias Utilizadas

- React
- Vite
- CSS
