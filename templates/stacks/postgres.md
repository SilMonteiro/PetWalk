# PostgreSQL Stack

This project uses **PostgreSQL**. When answering questions about this codebase:

1. **Primary source**: Use WebFetch on `https://www.postgresql.org/docs/current/` — the official documentation.
2. **Dialect**: SQL with PostgreSQL extensions, PL/pgSQL for stored procedures.
3. **Features**: JSONB, arrays, full-text search, window functions, CTEs.
4. **Tools**: psql, pgAdmin, pg_dump.

Prefer WebFetch on postgresql.org URLs over generic WebSearch.
