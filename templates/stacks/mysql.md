# MySQL Stack

This project uses **MySQL**. When answering questions about this codebase:

1. **Primary source**: Use WebFetch on `https://dev.mysql.com/doc/` — the official documentation.
2. **Dialect**: Standard SQL with MySQL extensions.
3. **Engines**: InnoDB (default, transactional), MyISAM (legacy).
4. **Tools**: MySQL Workbench, mysql CLI, phpMyAdmin.

Prefer WebFetch on dev.mysql.com URLs over generic WebSearch.
