# SQL Server Stack

This project uses **Microsoft SQL Server**. When answering questions about this codebase:

1. **Primary source**: Use WebFetch on `https://learn.microsoft.com/en-us/sql/` — the official documentation.
2. **Dialect**: T-SQL (Transact-SQL).
3. **Tools**: SSMS (SQL Server Management Studio), Azure Data Studio.
4. **Features**: Stored procedures, functions, views, indexes, transactions.

Prefer WebFetch on learn.microsoft.com URLs over generic WebSearch.
